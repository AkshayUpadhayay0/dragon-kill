# Dragon Kill Game

An interactive browser game featuring a glowing cyan dragon that follows your cursor. Hunt as many humans as you can in 60 seconds!

![Dragon Kill Game]
( https://akshayupadhayay0.github.io/dragon-kill/ )

## Features

- Smooth dragon cursor that follows mouse / touch
- Glowing cyan dragon with head, spine, and pointed tail
- 60-second timed rounds
- Score system
- Responsive dragon length based on screen size
- Works on desktop and mobile
- Clean start screen and game-over screen

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG (for the dragon graphics)

## How to Play

1. Open the game
2. Click **START GAME**
3. Move your mouse (or finger) — the dragon follows
4. Touch the red humans with the dragon’s head to eat them
5. Score as high as you can before the timer runs out
